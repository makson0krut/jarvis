# Утро — план дня

Пишешь дела обычными словами, утром ассистент рассказывает день по часам (голосом).
Это PWA: открывается как отдельное приложение с иконкой на главном экране, работает без интернета, данные хранятся на телефоне.

## Файлы

```
index.html            разметка
app.css               стили
app.js                вся логика (разбор текста, рассказ, голос, хранение)
sw.js                 service worker — офлайн-режим
manifest.webmanifest  имя, иконки, цвет — чтобы ставилось как приложение
icons/                иконки
```

## 1. Выложить в интернет (нужен HTTPS)

Без HTTPS не заработают офлайн-режим и микрофон. Самые простые бесплатные варианты:

**Netlify Drop — за минуту, без git**
1. Открой https://app.netlify.com/drop
2. Перетащи туда папку `utro-pwa` целиком.
3. Получишь ссылку вида `https://что-то.netlify.app`. Чтобы ссылка не потерялась, зарегистрируйся — сайт привяжется к аккаунту, и имя можно поменять.

**GitHub Pages**
1. Создай репозиторий, залей содержимое папки в корень.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту приложение будет на `https://<логин>.github.io/<репозиторий>/`.

Проверить локально: `python3 -m http.server 8000` в папке и открыть http://localhost:8000.

## 2. Поставить на телефон

**iPhone:** открой ссылку именно в Safari → кнопка «Поделиться» → «На экран „Домой“».
**Android:** открой в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на гл. экран»).

На iPhone у приложения с главного экрана своё хранилище, отдельное от Safari — добавляй дела уже в нём.

## Как пользоваться

- **Записать дела:** «завтра в 9:30 пара, в 14 спортзал на полтора часа, вечером позвонить Даше». Понимает: сегодня/завтра/послезавтра, дни недели («в пятницу»), даты («15.10»), «в 7 вечера», «с 10 до 12», «на час / полчаса / 40 мин», «утром/днём/вечером». Части разделяй запятой или новой строкой.
- **Надиктовать:** кнопка микрофона в поле ввода (если браузер умеет распознавать речь).
- **Спросить голосом:** «Какие сегодня планы?» / «Что у меня завтра?» — ассистент расскажет. Любую другую фразу он запишет как дело.
- **Утром** при первом открытии за день рассказ готовится сам; озвучка — по нажатию кнопки (телефоны не дают сайтам говорить без касания).
- **Настройки (шестерёнка):** имя для приветствия, ключ Claude API, резервная копия дел в файл и обратно.

## Нейросеть (необязательно)

Без ключа всё работает на встроенном разборе и шаблонном рассказе. С нейросетью приложение понимает любые формулировки и рассказывает день живым текстом. Настраивается в шестерёнке → «Нейросеть», там же кнопка «Проверить подключение».

- **OpenRouter — бесплатно.** Зарегистрируйся на https://openrouter.ai → Keys → Create key. Модели с `:free` в id бесплатны (лимит порядка 50 запросов в день — приложению хватает с запасом). По умолчанию стоит `deepseek/deepseek-chat-v3-0324:free`; бесплатные модели там время от времени меняются — если перестала отвечать, открой https://openrouter.ai/models, включи фильтр Free и вставь id другой модели.
- **DeepSeek напрямую** — https://platform.deepseek.com, модель `deepseek-chat`. Пробный баланс при регистрации, дальше платно, но копейки.
- **Claude** — https://console.anthropic.com, платно.
- **Другой OpenAI-совместимый API** — адрес `/chat/completions`, ключ и модель вручную.

Ключ лежит в браузере на твоём телефоне, в код и на GitHub он не попадает.

## Чего здесь нет

Само приложение утром не присылает уведомления: веб-приложению для этого нужен свой сервер с push-рассылкой. Можно добавить следующим шагом (например, бесплатный Cloudflare Worker с ежедневным push в 7:30).
